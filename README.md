# projet-final
## Présentation

Ce projet consiste à créer un site statique en HTML et CSS, à collaborer sur GitHub et à déployer le site sur Linux avec Docker.

## Arborescence

- `README.md` — documentation du projet
- `site/` — dossier du site
  - `index.html` — page d’accueil
  - `style.css` — mise en forme

## Aperçu en local

Ouvrir `site/index.html` dans le navigateur pour afficher le site.
